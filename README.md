# Emm1Typer
Mykrobe implementation and post processing for genotyping of emm1 Streptococcus pyogenes genomes


A genotyping scheme of emm1-ST28 (or locus variants thereof) of Streptococcus pyognes isolates. 
Scheme defined Lubeages/Clades/subclades of emm1 isolates to unify the many subgroups defined by public health and research groups.  

breifly this tool runs mykobe and perfomes a post-processing scipt in a similar nature to sonneityper to define emm1 genotypes
This also screens for key viruelnce factors (eg. SpeA, ssa) and AMR genes (ermB).
